DESCRIPCIÓN BREVE DEL PROYECTO
El proyecto es de un crud sin vistas echo en typescript donde se puede crear, listar, actualizar y eliminar
datos de solamente productos y clientes, los dos crud cuentan con validaciones para verificar si el usuario no ingreso
nada ademas de unas cuantas validaciones mas que son la de precio y stock que no permiten ingresar datos menores a 0
y en el caso del precio tampoco dejo dejarlo en 0, tambien los actualizar y eliminar cuentan con validaciones si no se encuentra
el ID que ingreso el usuario, el proyecto no cuenta con ninguna enumeracion.

DATOS OPTENIDOS EN LA SIMULACION
Todo funciona como debe el unico detalle a decir es sobre la estetica de este mismo ya que no puse ninguna separacion entre los textos
haciendo que cada pregunta en la consola se vea junta.
